# Lucide SVG icons

Source: https://github.com/lucide-icons/lucide/tree/main/icons
License: [ISC / Feather MIT notices](LICENSE)

필요한 SVG 원본만 보관합니다. 기존 프로젝트 방식에 맞춰 Vue 템플릿에는 SVG를 인라인으로 사용하며, `stroke="currentColor"`로 테마 색상을 따릅니다. 장식 아이콘에는 `aria-hidden="true"`, `focusable="false"`를 적용하고 버튼과 링크의 이름은 기존 텍스트로 제공합니다.
