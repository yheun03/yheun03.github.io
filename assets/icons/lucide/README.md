# Lucide SVG icons

Source: https://github.com/lucide-icons/lucide/tree/main/icons
License: [ISC / Feather MIT notices](LICENSE)

아이콘은 기존 프로젝트 방식에 맞춰 Vue 템플릿에 인라인으로 사용합니다. 중복되는 SVG 파일은 제공하지 않으며, 위 출처와 라이선스를 보관합니다. `stroke="currentColor"`로 테마 색상을 따릅니다. 장식 아이콘에는 `aria-hidden="true"`, `focusable="false"`를 적용하고 버튼과 링크의 이름은 기존 텍스트로 제공합니다.
