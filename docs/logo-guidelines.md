# eun. 최종 로고 설계 기준

## 사이트 적용 파일

- 워드마크: `assets/icons/logo-eun.svg`
- 파비콘: `assets/icons/favicon-eun.svg`
- 브라우저 호환 아이콘: `assets/icons/favicon-eun.ico`
- 홈 화면 아이콘: `assets/icons/apple-touch-icon-eun.png`
- 소개 페이지 공유 이미지: `assets/images/common/og/about.jpg`

워드마크와 파비콘의 정확한 경로와 제어점은 위 SVG 원본에 있습니다. 로고를 수정하면 `pages/about.vue`의 애니메이션용 인라인 SVG도 같은 경로로 맞춥니다.

## 워드마크

모든 수치는 SVG 설계 단위입니다.

- viewBox: `0 0 240 98`
- u와 n의 공통 폭: 56
- 수직획 두께: 16
- 곡선 상하와 중앙 가로획의 기준 두께: 14
- 직선 기준 상단: y=16, 기준선: y=82
- 곡선 상단: y=14, 곡선 하단: y=84, 시각 보정: 2
- n과 u는 로컬 좌표 `(28, 49)`를 중심으로 180° 회전 관계
- u의 시작 x=78, n의 시작 x=148
- e 끝단 절단각: 45°, 직선 모서리: 90°
- 외곽 경계 사이 간격: e에서 u까지 12, u에서 n까지 14, n에서 점까지 12
- 점 중심: `(224, 74)`, 반지름: 8, 지름: 16
- 점의 하단은 기준선 y=82에 정렬
- 글자 색상: `#191f28`, 점 색상: `#f12810`

곡선은 원호가 아닌 3차 베지어로 설계했습니다. 회전한 n과 u를 560×980px로 렌더링해 비교했을 때 모든 채널 차이는 0이었습니다.

## 파비콘

- viewBox: `0 0 64 64`
- 배경: `#191f28`, 모서리 반지름: 12, 외곽선 없음
- e는 워드마크와 같은 경로에 `matrix(0.6 0 0 0.6 5.2 2.6)` 적용
- e의 색상: `#ffffff`
- e의 경계: x=10..44.8, y=11..53
- 수직 기준 획: 9.6, 가로 기준 획: 8.4
- 점 중심: `(53, 46.8)`, 반지름: 5, 지름: 10
- 점의 하단은 e의 기준선 y=51.8에 정렬
- 경계 기준 여백: 왼쪽 10, 오른쪽 6, 위와 아래 11
- e와 점의 수평 경계 간격: 3.2
- 16px 출력 기준: e 높이 10.5px, 수직획 2.4px, 점 지름 2.5px
- ICO에는 16px, 32px, 48px PNG 포함
- 홈 화면 아이콘은 180×180px 정사각형 배경 사용

## 사이트 표시 크기

SVG의 비율을 유지하고 CSS에서 너비만 조절합니다.

- 헤더: 기본 104px, 900px 이하 88px
- 푸터: 기본 120px, 640px 이하 104px

소개 페이지 로고는 해당 섹션에 진입할 때 글자와 점이 순서대로 나타납니다. 동작 줄이기 설정에서는 정적으로 표시합니다.
