# 소셜 공유 이미지

- 최종 이미지: `assets/images/common/og/*.jpg`, 1200 × 630px
- 원본 일러스트: `assets/images/common/og/sources/*.png`
- 전체 이미지 재생성: `node scripts/generate-og-images.mjs`
- 포트폴리오 상세 이미지만 재생성: `node scripts/generate-og-images.mjs --details-only`

한국어 프로젝트 제목, 사용 기술, 작업 기간 또는 화면 캡처를 변경하면 위 명령어로 이미지를 다시 생성합니다. 프로젝트 정보는 `data/works/ko.json`을 사용합니다.

원본 일러스트 4종은 내장 이미지 생성 도구로 제작했습니다. 프로젝트 상세 이미지는 기존 화면 캡처에 프로젝트별 제목, 작업 기간과 사용 기술을 조합합니다. 공개 화면 캡처가 없는 프로젝트는 실무 프로젝트 일러스트를 사용합니다.

## 일러스트 생성 프롬프트

아래 내용은 이미지 생성에 사용한 프롬프트를 한국어로 옮긴 것입니다.

### 공통 스타일

포트폴리오 소셜 공유 이미지에 사용할 입체적인 콘셉트 일러스트입니다. 종이와 무광 세라믹 질감을 활용해 간결하고 정돈된 형태로 표현합니다. 흰색과 차가운 연회색을 중심으로 구성하고, 짙은 회색의 세부 표현과 절제된 빨간색 `#e53935` 강조 요소를 더합니다. 부드러운 스튜디오 조명과 그림자를 사용합니다.

가로세로 비율은 약 1.9:1입니다. 사물은 오른쪽 절반에 모으고, 왼쪽 절반은 나중에 글자를 배치할 수 있도록 밝은 회색 여백으로 남깁니다. 이미지에 글자, 로고 또는 워터마크를 넣지 않습니다.

### 소개 페이지

웹 퍼블리셔의 화면 제작 과정을 표현한 정물 일러스트입니다. 정밀한 타이포그래피 블록, 브라우저 프레임, 작고 선명한 빨간 구, 가지런히 정렬된 화면 구성 요소를 배치합니다.

### 경력과 학업 페이지

경력과 배움의 성장을 표현한 정물 일러스트입니다. 흰 종이 블록으로 만든 상승 계단, 단계별 이정표를 연결하는 가느다란 붉은 실, 펼친 공책과 학사모를 연상시키는 작은 기하학적 형태를 배치합니다.

### 실무 프로젝트 목록

웹 퍼블리싱 실무를 표현한 정물 일러스트입니다. 데스크톱 브라우저 대시보드, 가지런히 쌓인 CMS 화면 패널, 차트 카드, 데이터 표와 작은 빨간 강조 블록을 배치합니다.

### 개인 프로젝트 목록

직접 만든 웹 서비스를 표현한 정물 일러스트입니다. 공중에 떠 있는 작은 브라우저 창, 비행기 실루엣, 레이더 원형 표시, 말풍선과 야구공을 연결해 개인 애플리케이션 모음을 표현합니다.

## 메타 정보

소개 페이지와 경력 페이지는 `i18n/ko.json`, `i18n/en.json`에 정의한 페이지별 문구를 사용합니다. 프로젝트 목록은 같은 파일의 갤러리 문구를 사용합니다.

포트폴리오 상세 페이지의 문서 제목과 설명은 `data/works/ko.json`, `data/works/en.json`의 현재 화면 언어에 해당하는 제목과 소개를 사용합니다. 공유용 제목, 설명, 이미지 대체 텍스트와 언어 정보는 화면 언어가 바뀌어도 한국어로 유지합니다. 상세 이미지 안의 제목, 분류와 작성자 문구도 한국어로 표시합니다.

모든 페이지는 `usePortfolioSeo`를 통해 오픈 그래프, 트위터 카드와 구조화 데이터를 설정합니다. 메인 페이지는 기존 이미지와 메타 정보를 유지합니다.
