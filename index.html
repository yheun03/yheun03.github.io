What I do

화면 구현부터 공통화와 운영까지 담당합니다.

HTML과 SCSS로 디자인 시안을 구현합니다. PC와 모바일의 화면 크기에 맞춰 레이아웃을 조정합니다.

Vue로 입력 폼, 데이터 그리드, 모달을 구현하고 조회와 편집 등 화면 동작을 연결합니다.

디자인 토큰과 공통 컴포넌트로 반복 작업을 줄이고, 여러 화면에 일관된 기준을 적용합니다.

컴포넌트 사용 방법, 작업 규칙, 예제 코드를 문서로 정리하고 팀원에게 공유합니다.

작업 방식

작은 디테일이 모여, 좋은 경험이 됩니다.

  1. [01]

    화면과 상태 정리

    요구사항과 디자인을 확인하고, 입력과 조회부터 오류와 로딩까지 필요한 화면 상태를 정리합니다.

  2. [02]

    컴포넌트 구현

    반복되는 UI를 컴포넌트로 분리합니다. SCSS와 디자인 토큰으로 화면별 스타일을 관리합니다.

  3. [03]

    검수와 운영 대응

    화면 크기와 브라우저별 동작을 확인하고, 사용 방법을 문서화합니다. 운영 중 발견된 오류를 수정합니다.
