경력과 학업 이력

회사에서 맡은 일과 학교에서 배운 내용을 시기별로 정리했습니다.

2020.07~현재

회사

조앤소프트 / DX 솔루션 2팀 / 대리 / 웹 퍼블리셔 및 Vue UI 개발

웹 퍼블리싱을 중심으로 구축과 운영, 리뉴얼을 맡고 Vue 컴포넌트와 프론트엔드 구조 설계까지 역할을 넓혀 왔습니다.

  • 프로젝트별 전체 화면 퍼블리싱 전담
  • Vue 기반 화면 구현
  • CMS 커스터마이징
  • 공통 컴포넌트와 UI 구조 설계
  • 운영 유지보수

  1. 2026

    Nuxt 3 공통 UI와 사내 프레임워크

    Vue 3와 Composition API로 포트폴리오와 업무 UI를 작업했습니다. 공통 컴포넌트, SCSS 모듈과 디자인 토큰을 정리하고 정적 배포 환경도 설정했습니다.

  2. 2025

    홈페이지 운영과 CMS 리뉴얼

    홈페이지 운영, 리뉴얼과 CMS 커스터마이징을 맡았습니다. 설정 가이드와 인수인계 자료를 작성했고, 회사 업무와 대학 졸업 준비를 병행했습니다.

  3. 2024

    Vue 3 업무 화면 개발

    Vue 3 기반 관리, 업무 시스템에서 컴포넌트, 상태 관리, 라우팅과 SCSS를 작업했습니다. 화면을 검수하고 협업사와 고객사 피드백을 반영했습니다.

  4. 2023

    WebSquare, SW개발 L5 자격 취득

    WebSquare Certified Publisher와 SW개발 L5를 취득했습니다. 화면 명세와 마크업 규칙을 정리하고 개발 산출물 작성 방법을 익혔습니다.

  5. 2022

    솔루션 UI 공통화

    자사 솔루션과 구축 프로젝트의 레이아웃, 컴포넌트, SCSS 변수를 공통으로 정리했습니다. Naver Cloud Platform Certified Associate도 취득했습니다.

  6. 2021

    업무 시스템 구축 프로젝트 참여

    업무 시스템의 와이어프레임, 디자인, HTML, CSS와 인터랙션을 작업했습니다. 고등학교를 졸업하고 회사 업무를 이어갔습니다.

  7. 2020

    웹 퍼블리셔 정식 입사

    7월 웹 퍼블리셔 정식 사원으로 입사했습니다. 반응형 화면과 크로스브라우징을 작업하고, 고객 요구사항 변경과 운영 요청에 대응했습니다.

  8. 2019

    OJT 현장실습

    2019년 12월부터 OJT 현장실습에 참여했습니다. 학교와 동아리에서 배우던 웹 제작을 회사 프로젝트에 적용하기 시작했습니다.

2021.03 ~ 2025.02

대학교

한국공학대학교 컴퓨터전자공학과 편입 / 졸업 (4.45/4.5) / 전적대 모바일소프트웨어학과 (4.27/4.5)

전적대 모바일소프트웨어학과를 졸업한 뒤 한국공학대학교 컴퓨터전자공학과에 편입해 4.45/4.5의 학점으로 졸업했습니다. 전공 수업과 회사 업무를 병행했고, 학과대표 / 학회장으로 학생회 설립과 행사를 이끌었습니다.

  • 한국공학대학교 컴퓨터전자공학과 편입 / 졸업 (4.45/4.5)
  • 전적대 모바일소프트웨어학과 졸업 (4.27/4.5)
  • 학과대표 / 학회장 (학생회 설립)
  • 회사 실무 병행

  1. 2025

    일하며 대학을 졸업했습니다

    회사 업무와 학업을 병행하며 한국공학대학교 컴퓨터전자공학과를 4.45/4.5의 학점으로 졸업했습니다.

  2. 2024

    학회장 활동

    2024년 2월까지 학회장을 맡아 학과 점퍼, MT, 해커톤 같은 프로그램을 기획 / 주최했습니다. 전공 수업에서는 웹 제작 경험을 이론과 연결했습니다.

  3. 2023

    한국공학대학교 편입, 학생회 설립

    전적대 졸업 후 한국공학대학교 컴퓨터전자공학과 3학년으로 편입했습니다. 학과대표를 거쳐 학회장을 맡으며 학생회 설립, 셔틀버스 배차, 주차 문제 등을 조율했습니다.

  4. 2022

    모바일소프트웨어 전공 수업

    전적대 모바일소프트웨어학과에서 앱과 소프트웨어 개발 흐름을 익혔습니다. 업무와 수업 일정을 함께 관리하는 방식도 배웠습니다.

  5. 2021

    회사와 대학 생활 병행

    고등학교 졸업 후 전적대 모바일소프트웨어학과에 입학했습니다. 회사 업무를 이어가며 전공 공부를 시작했습니다.

2018.03 ~ 2021.01

고등학교

웹디자인 / 동아리 MOD

웹디자인과 MOD 동아리에서 HTML / CSS / JavaScript 기초를 익혔습니다. 온라인 학습과 학생회장 선거 사이트처럼 실제 학생이 쓰는 웹을 만들며 경험을 넓혔습니다.

  • MOD 웹디자인 동아리 회장
  • 온라인 학습 / 학생회장 선거 사이트 개발
  • 웹디자인기능사 / 정보처리기능사

  1. 2020

    온라인 학습, 선거 사이트 제작

    원격 수업용 온라인 학습 사이트와 학생회장 선거 페이지를 제작했습니다. 교내 프로젝트에서 익힌 마크업과 협업 방식을 OJT 현장실습과 실무로 이어갔습니다.

  2. 2018 ~ 2019

    웹 제작 공부와 MOD 동아리 운영

    HTML / CSS / JavaScript 기초를 익히고 MOD 회장으로 커리큘럼과 과제를 운영했습니다. 관련 자격을 취득하고 교내 웹 TF를 이끌며 실사용자와 마감을 처음 경험했습니다.
