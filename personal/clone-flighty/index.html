플라이티 UI 클론

Flighty의 주요 화면을 Vue 3로 구현한 클론입니다. 32편의 항공 데이터로 목록, 상세, 검색, 지도, 패스포트, 통계 화면을 연결하고, 반응형과 다국어, 단위 설정을 적용했습니다.

작업 내용과 결과

담당한 작업

  • Flighty 4.8.2 PC 버전 화면을 캡처하고 정보 구조, 폰트 계층, 카드 구성, 인터랙션 밀도를 분석
  • Figma 최종 시안을 기준으로 Vue 3, Vite, Vue Router 기반의 반응형 화면과 공통 UI 컴포넌트 구현
  • 32편의 항공 데이터를 공통 JSON으로 연결해 목록, 상세, 검색, 패스포트, 통계 화면의 데이터를 일관되게 구성
  • MapLibre, OpenFreeMap으로 항공 경로 지도를 구현하고 검색, 기간 선택, 상세 항공편에 따라 지도 데이터를 연동
  • 한국어, 영어, 일본어, 기기 언어와 거리, 속도, 고도 단위 설정을 브라우저에 저장해 전체 화면에 적용

작업 결과

  • 항공편 원천 데이터를 중심으로 시간, 지연, 시차, 통계를 계산해 여러 화면이 동일한 결과를 공유하도록 구현
  • 기본 UI와 플라이티 전용 조합 컴포넌트를 분리하고 props 변형으로 재사용 가능한 퍼블리싱 구조 완성

기술 및 구현 특징

  • 32편의 항공 데이터를 여러 화면에서 사용
  • 검색, 기간별 항로 지도와 기체 정보
  • 반응형, 4개 언어, 단위 변환

사용 기술

  • Vue 3
  • JavaScript
  • Vue Router
  • Vite
  • SCSS
  • MapLibre
  • Figma
