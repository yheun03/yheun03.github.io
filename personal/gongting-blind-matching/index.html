공팅 블라인드 매칭 서비스

한국공학대학교 학생을 대상으로 만든 블라인드 매칭 서비스입니다. 성향과 관심사를 입력해 상대를 찾을 수 있도록 소개, 가입, 프로필, 매칭, 결과 화면을 제작하고 GitHub Pages에 배포했습니다.

사이트 보기GitHub

유형
개인 / 모바일 웹 서비스
기간
2024.05.16~2024.07.21
소요 시간
구축 약 1주 / 운영 및 고도화 약 2개월
역할
UI 디자인 공동 참여, 전체 화면 퍼블리싱 담당

작업 내용과 결과

담당한 작업

  • intro / 회원(user) / 매칭(match) 흐름을 `html/` 정적 페이지와 `intro.html` 진입점으로 구성
  • 모바일 중심 UI 디자인 방향 수립, 브랜드 톤 / 그래픽 / SCSS / JS를 `resources/`에 정리
  • UI 컴포넌트 샘플을 `component.html`로 분리해 화면 단위 퍼블리싱 재사용
  • GitHub Pages(`yheun03.github.io/gongting`) 배포 및 파비콘 / 에셋 세트 구성

작업 결과

  • 초기 서비스에서 1차 171명, 2차 121명의 참여 경험을 기록
  • GitHub 저장소로 화면 / 리소스를 버전 관리해 포트폴리오 아카이브와 별도로 유지

기술 및 구현 특징

  • 모바일 화면 구현과 서비스 출시
  • 참여 기록과 피드백을 반영한 후속 기획

사용 기술

  • HTML
  • SCSS
  • JavaScript
  • Figma
  • Photoshop
  • Illustrator
  • GitHub Pages
