메이트메이트(MATEMATE) 룸메이트 매칭

한국공학대학교 방학 / 캡스톤 팀 프로젝트로 만든 기숙사 룸메이트 매칭 모바일 웹입니다. 랜덤 배정이나 지인 추천 대신 생활 습관 / 성향 조건을 입력해 맞는 상대를 찾도록 설계했습니다. 소스와 배포는 team-matemate/matemate 저장소와 Firebase에서 관리했습니다.

사이트 보기GitHub

유형
팀 / 방학 / 캡스톤 (모바일 웹)
기간
2025.01.04~2025.01.30
소요 시간
약 4주
역할
서비스 기획 주도, UI 디자인 공동 참여, 전체 화면 퍼블리싱 담당 (team-matemate)

작업 내용과 결과

담당한 작업

  • 문제 정의 / 서비스 기획 / 매칭 / 인증 / 채팅 / 게시판 등 사용자 흐름과 IA 설계
  • `public/html/`에 auth / match / chat / board / cutline / user / main 화면 퍼블리싱 및 SCSS 컴포넌트 구조 정리
  • Firebase Hosting(루트 → main), Firestore / Storage rules, Cloud Functions 백엔드 연동 구성
  • Swiper / 공통 JS로 매칭 / 목록 인터랙션 구현, C2C 반복 수정에 맞춘 UX 정리

작업 결과

  • 4주간의 팀 협업으로 핵심 사용자 흐름을 갖춘 MVP와 배포 파이프라인 완성
  • 체크리스트 / 개인 게시글 방식 대비 자동 조건 매칭이라는 서비스 차별점을 UI 흐름으로 구현

기술 및 구현 특징

  • 팀 프로젝트 기획, 퍼블리싱 담당
  • Firebase 호스팅, DB, 함수 사용

사용 기술

  • HTML
  • SCSS
  • JavaScript
  • Firebase Hosting
  • Firestore
  • Cloud Functions
  • Figma
