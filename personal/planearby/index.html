Planearby / 주변 항공기 레이더

운전하거나 운동할 때 보이는 비행기가 궁금해 만들었습니다. 주변 30km의 항공기를 레이더와 공항 전광판 형태로 보여 줍니다. Flightradar24에서 자주 쓰던 기능 중 주변 항공기 조회에 집중했고, Codex Sol 6.1만으로 제작했습니다.

작업 내용과 결과

담당한 작업

  • Flightradar24 사용 경험을 바탕으로 내 주변 항공기 확인에 집중하도록 기능 범위 정의
  • Vue 3 + Vite + JavaScript + SCSS로 대시보드와 설정 / 위치 선택 화면 구현
  • PC에서는 전광판과 레이더를 나란히, 모바일에서는 레이더를 먼저 보여주는 반응형 레이아웃 구성
  • 항공편 정보를 분할 플랩 애니메이션으로 표현하고 항공기 선택 / 위치 갱신 주기 자동 전환 / 일시정지 구현
  • Geolocation API와 adsb.lol / adsbdb를 연동해 반경 30km의 항공기와 참고 노선을 조회하고 네트워크 상태에 따라 5초 / 10초 / 15초로 갱신
  • Leaflet / OpenStreetMap 지도, 주소 검색과 위도, 경도 입력으로 조회 위치 직접 선택 기능 구현
  • 라이트 / 다크 테마, 한국어 / 영어 / 일본어, 휴대폰 위치, 나침반 연동과 수동 방향 설정 지원
  • 키보드 조작, 상태, 레이더 거리 눈금 음성 안내와 모션 감소 설정을 적용하고 사전 렌더링 / SEO / GitHub Pages 배포 구성

작업 결과

  • 주변 항공기의 거리와 방향을 시각적으로 확인하고 전광판에서 상세 정보를 읽는 화면 흐름 완성
  • 위치 권한 거부 후 재요청, GPS, 나침반 실패 안내와 지도, 좌표 입력을 통한 대체 경로 마련
  • 요청 취소, 노선 캐시, API 한도 대기와 오류 안내를 포함해 조회 상태별 화면 구현

기술 및 구현 특징

  • 레이더와 공항 전광판을 결합한 데이터 시각화 및 분할 플랩 인터랙션
  • 반응형 화면, 다국어, 테마와 접근성을 함께 고려한 Vue UI 구현
  • 캡처는 서비스에서 제공하는 가상 항공기 예시 화면이며 실제 운항 정보와 구분

사용 기술

  • Vue 3
  • Vite
  • JavaScript
  • SCSS
  • Leaflet
  • Geolocation API
