조앤소프트 프레임워크 및 퍼블리싱 표준화

프로젝트마다 반복되는 초기 설정과 업무 UI를 공통으로 사용할 수 있도록 Nuxt 3 기반 사내 프레임워크를 구축했습니다. 라우팅, 상태 관리, API와 다국어 처리, 공통 컴포넌트, SCSS 토큰을 정리하고 예제 화면과 개발 가이드를 함께 제작했습니다.

역할
Nuxt 3 프론트엔드 구조와 공통 UI 설계, 퍼블리싱 표준화 및 개발 가이드 작성

작업 내용과 결과

담당한 작업

  • 자동 라우팅 / 컴포넌트 자동 import / Pinia 상태 관리 / Axios API 플러그인 등 기반 구조 정리
  • AppButton / AppInput / AppSelect / AppDatePicker / AppProgress / Chart / AG Grid 등 재사용 컴포넌트 제작
  • 컴포넌트마다 size / disabled / readonly / focus / error / loading / active 등 실무 상태를 반영
  • BEM 네이밍과 디자인 토큰(색 / 타이포 / 간격 / 상태 / 반응형)을 기준으로 SCSS 구조 설계
  • composable / 레이아웃 / 공통 플러그인을 실무 적용 가능한 형태로 구성하고 예제 페이지 제작
  • 컴포넌트 네이밍, 폴더 구조, API와 다국어 처리 규칙을 신규 프로젝트에서 재사용할 수 있도록 정리
  • 실무용 목록, 대시보드, 현장 키오스크 예제와 스타일 가이드, 개발 문서 제작

작업 결과

  • 프로젝트마다 반복 구축하던 기본 UI / 레이아웃 / API 연동 / SCSS 구조를 프레임워크화
  • 컴포넌트 / API 구조 / 예제 페이지를 함께 정리해 신규 프로젝트 착수 속도를 높이는 협업 표준 구축

기술 및 구현 특징

  • Nuxt 3 공통 프레임워크와 업무 화면 예제
  • 상태별 UI 컴포넌트, 디자인 토큰과 SCSS 규칙
  • 폴더 구조, API, 다국어와 개발 가이드 표준화
