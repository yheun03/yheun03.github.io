한진칼 및 계열사 리뉴얼

한진칼과 계열사 홈페이지의 Vue 컴포넌트를 ICE 5.0 CMS에 맞게 수정했습니다. 환경 설정과 개발 방법을 가이드로 작성해 교육 때 공유하고, 협력사와 고객사의 기술 문의에도 대응했습니다.

유형
기업 사이트 / CMS
기간
2025.02~07
소요 시간
약 6개월
역할
개발 및 환경 설정 가이드 작성, 교육과 운영 안정화 지원, 협력사와 고객사 기술 커뮤니케이션 담당

작업 내용과 결과

담당한 작업

  • 콘센트릭스가 전달한 Vue 컴포넌트를 ICE 5.0 CMS 구조에 맞게 커스터마이징 / 재구성
  • ICE가 요구하는 파일 구조를 직접 설계하고, 컴포넌트를 재사용 / 확장 가능한 CMS 친화형으로 변환
  • 공식 가이드 부재로 생긴 교육 혼선을 해소하기 위해 개발 구조 / ICE 세팅 가이드를 직접 기획 / 제작해 콘센트릭스 / 한진칼에 공유
  • ICE 내부 기능 미비로 발생한 이슈를 ICE 담당자와 지속 커뮤니케이션하며 해결 속도 단축
  • 퍼블리싱 가이드를 유지하면서 다양한 디바이스 대응 마크업 / 스타일링을 주도적으로 수정 / 적용
  • 2025.04 ICE 담당자 롤아웃 이후 대외 커뮤니케이션 전담, 내부 산출물 정리 / 공유로 협업 효율 유지

작업 결과

  • 환경 설정과 개발 가이드를 정리해 교육과 협업 때 공유
  • ICE 기능에 맞춰 컴포넌트를 수정하고 재사용할 수 있도록 정리
  • 콘센트릭스, 아이온, 한진칼 사이의 기술 문의와 작업 내용 조율

기술 및 구현 특징

  • ICE 5.0 CMS 컴포넌트 수정
  • 설정 가이드 작성과 교육
  • 협력사, 고객사 기술 문의 대응

사용 기술

  • IntelliJ
  • ICE 5.0
  • Microsoft Teams
  • Word
  • PowerPoint
  • HTML
  • SCSS
  • Vue.js
