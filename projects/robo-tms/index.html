Robo TMS 솔루션

TMS 운영 중 확인한 고객 요구를 반영해 자사 물류 솔루션을 만들었습니다. 기획에 함께 참여하고, 고객용 앱의 UI 디자인과 Vue, SCSS 퍼블리싱을 맡았습니다.

유형
자사 솔루션
기간
2024.02~04
소요 시간
약 3개월
역할
기획 공동 참여, 전체 화면 퍼블리싱과 UI 디자인 담당

작업 내용과 결과

담당한 작업

  • 운영 중 수집한 고객 요구 / 문의를 바탕으로 기획에 참여
  • 고객용 애플리케이션의 UI / UX 디자인을 직접 설계
  • Vue / SCSS 기반으로 전체 화면 퍼블리싱 전담
  • 개편된 UI와 더 편한 사용 흐름으로 사용성 개선

작업 결과

  • TMS 운영에서 확인한 반복 문의를 화면 흐름과 상태 표현 개선에 반영
  • 운영 경험을 제품화로 연결한 자사 솔루션 결과물 완성

기술 및 구현 특징

  • 기획 참여, UI 디자인, 퍼블리싱
  • 운영 중 받은 고객 요구 반영
  • Vue, SCSS 고객용 앱

사용 기술

  • Vue
  • SCSS
  • Figma
