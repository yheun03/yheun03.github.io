삼화페인트 생태공장 대시보드

삼화페인트 생태공장의 공정, 환경 데이터를 보여 주는 대시보드입니다. 전체 화면 퍼블리싱을 맡아 카드, 차트, 상태 표시의 간격과 색상, 정렬을 맞췄습니다.

유형
SI / 대시보드
기간
2026.05
소요 시간
약 1개월
역할
전체 화면 퍼블리싱 단독 담당, 기존 UI 규칙 개선 참여

작업 내용과 결과

담당한 작업

  • 대시보드 Client 화면 전체 퍼블리싱 — 카드, 데이터 영역, 상태 표시, 차트, 정보성 UI
  • 화면별로 흩어져 있던 위계 / 간격 / 정렬 기준을 통일해 일관된 카드형 레이아웃 정립
  • 정상 / 경고 등 상태 표현을 색 / 라벨 규칙으로 정리해 데이터 판독성 강화
  • 차트 / 수치 영역의 반응형 대응으로 다양한 해상도에서 가독성 유지
  • 기존 화면의 불규칙한 스타일을 정리하고 카드 / 상태 / 차트 UI 규칙을 문서화

작업 결과

  • 화면별로 달랐던 간격 / 정렬 / 상태 색을 하나의 규칙으로 통일
  • 카드와 상태 표현 기준을 공통화해 신규 위젯도 같은 시각 규칙으로 추가할 수 있게 구성

기술 및 구현 특징

  • 공정, 환경 데이터 대시보드
  • 카드, 차트, 상태 표시 통일
  • 전체 화면 퍼블리싱

사용 기술

  • Visual Studio Code
  • Git
  • Vue
  • JavaScript
  • SCSS
  • HTML
