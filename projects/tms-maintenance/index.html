TMS 운영 / 보수

태림포장, 대영포장 TMS의 속도 저하 원인을 단위 테스트로 찾아 해결한 뒤, 고객 문의와 화면 보수도 맡았습니다. 개선 작업 후 일 평균 15건 이상이던 불편 접수가 2건 수준으로 줄었고, 처리 방법을 문서로 남겼습니다.

유형
SM 운영 / 보수
기간
2023.05~2023.07
소요 시간
약 3개월
역할
고객 이슈 접수, 분류, 리포트와 보수 퍼블리싱 담당

작업 내용과 결과

담당한 작업

  • 속도 저하 이슈를 단위 테스트로 특정해 원인 해결
  • 자발적으로 고객 응대를 맡아 속도 / 화면 오류 등 불편사항 즉시 처리
  • 미해결 이슈는 개발팀에 신속 보고하고, 해결 케이스를 산출물로 정리
  • 반복되는 불편 사항을 분석해 UX/UI 개선 / 보수 화면(Nexacro)으로 연결

작업 결과

  • 일 평균 불편 접수 15건 이상 → 2건 수준으로 감소
  • 해결 케이스 산출물이 동일 이슈 재발 시 대응 자료로 재사용됨

기술 및 구현 특징

  • 속도 저하 원인 확인과 수정
  • 고객 문의 접수, 분류, 응대
  • 반복 이슈 처리 문서

사용 기술

  • Nexacro
